## Data scope

This directory provides 14 original GeoTIFF layers for 2019. The source product archive covers 2008–2020; this subset does not represent the complete archive. These global-land layers are model-derived nitrogen-deposition estimates, not direct observations or atmospheric chemistry transport model output, and do not directly represent aerosol pH.

## Variables and units

The nitrogen-deposition layers use kg N ha-1 yr-1, based on the paper and supplementary table. Units are not embedded in the GeoTIFF tags.

## Native grid

WGS 84 Albers equal-area projected grid; central meridian 105°, standard parallels 25°/47°, false easting 4,000,000 m; 2307×1430; pixel size ±14,529.2333956 m. This is not a native 0.125° latitude/longitude grid.
