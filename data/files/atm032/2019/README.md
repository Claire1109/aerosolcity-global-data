Scope: This candidate contains only 14 selected annual global-land nitrogen-deposition estimate layers for 2019 from the source archive covering 2008–2020. The layers are model-derived estimates, not direct observations or atmospheric chemistry transport model output, and do not directly represent aerosol pH. The archive covers 2008–2020; this candidate contains only the 2019 annual layers listed here, not the complete archive.

Variables and units: the nitrogen-deposition layers use kg N ha-1 yr-1, based on the paper and supplementary table; units are not embedded in the GeoTIFF tags.

Native grid: WGS 84 Albers equal-area projected grid; central meridian 105°, standard parallels 25°/47°, false easting 4,000,000 m; 2307×1430; pixel size ±14,529.2333956 m; not a native 0.125° lat/lon grid.
